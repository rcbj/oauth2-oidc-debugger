Choose a debugger Protocol

Which identity protocol do you want to debug?

OAuth2 / OIDC Protocol Authorization Code, Implicit, Client Credentials, Resource Owner, Device, and Token Exchange grants plus all OIDC flows — with JWT, JWKS, introspection, and userinfo tools. SAML Protocol SAML 2.0 SP-initiated SSO: load IdP metadata, build and sign an AuthnRequest, capture the SAMLResponse at the ACS, and inspect the assertion and its attributes. WS-Trust Protocol WS-Trust (all protocol versions) against an STS: build a SOAP RequestSecurityToken for Issue, Renew, Validate, or Cancel with WS-Security and WS-Addressing, sign/encrypt it, and inspect the issued token in the response. SD-JWT VC Issuance Issue a Selective Disclosure JWT Verifiable Credential (SD-JWT, RFC 9901) over OID4VCI. Choose how the issuance starts — wallet-initiated, or an issuer's Credential Offer — then read the issuer and authorization server metadata, authorize with the OIDC Authorization Code flow, prove possession of a holder key, inspect the credential and its disclosures, and refresh it when it goes stale. SD-JWT VC Presentation Present a Selective Disclosure JWT VC to a verifier over OID4VP. Read the verifier’s Authorization Request and its DCQL query, see exactly which claims are being asked for, choose which Disclosures to send, sign the Key Binding JWT over the request’s nonce, and read the verifier’s verdict check by check.
